Generic Application Security Reference Architecture

A high-level control-path model for secure design and architecture review.

Untrusted zone

External Entry Points

End users, client applications, APIs, uploaded content, and approved external services.

Application trust boundary

Application Boundary

Ingress, application services, identities, authorization decisions, business actions, and service-to-service calls.

Sensitive zone

Sensitive Data Stores

Business data, files, secrets, configuration, and other protected application assets.

Validate entryApproved interfaces, input validation, rate limits, and secure failure behavior.
Enforce identityAuthentication, object-level authorization, least privilege, and bounded service identities.
Protect dataAccess control, encryption, retention, recovery, and controlled data movement.

Privileged Access

Separate administrative path with strong authentication, approval, scoped permissions, and recorded activity.

Audit Evidence & Monitoring

Security-relevant events from entry points, application decisions, privileged actions, and data access are retained for detection, investigation, and remediation verification.
